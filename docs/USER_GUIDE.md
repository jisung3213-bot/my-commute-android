# 나만의 출퇴근 사용 방법

## 처음 설정하기

1. **로그인** 화면에서 이메일 계정으로 가입하거나 로그인합니다.
2. **루틴** 탭에서 출근길과 퇴근길을 따로 설정합니다. 출발지·도착지와 필요한 경우 경유지 최대 두 곳을 검색합니다.
3. 목표 도착 시각과 여유시간을 정하고, 한 줄의 월~일 버튼에서 도착일 기준 반복 요일을 고릅니다.
4. **경로 검색**에서 추천 후보와 다른 후보를 확인하고 **이 경로 선택**을 누릅니다. 각 방향에서 평소 쓸 경로를 기본으로 지정합니다.

## 화면별 기능

| 화면 | 사용할 수 있는 기능과 이동 |
| --- | --- |
| 로그인 | 이메일 회원가입·로그인 후 홈으로 이동합니다. 이전에 저장한 계정별 루틴과 설정을 가져옵니다. |
| 홈 | 다음 목표 도착 일정에 맞춰 기본 출근길 또는 퇴근길을 표시합니다. 방향을 직접 고르거나 다른 저장 경로를 열 수 있습니다. 실시간 이동과 알림 로그 버튼이 있습니다. |
| 루틴 | 장소, 목표 시각, 여유시간, 요일을 편집합니다. 장소 검색을 열고 후보를 골라 저장하거나 지도에서 미리 봅니다. |
| 장소 검색 | 장소 이름 두 글자 이상을 입력합니다. 항목을 선택하면 이름과 위치가 출발지·도착지·경유지 중 요청한 칸에 반영됩니다. |
| 지도 | 출발지·도착지와 경유지의 핀을 표시합니다. 경로 표시를 켜면 이용 가능한 상세 경로를 선으로 표시합니다. |
| 실시간 이동 | 저장 경로, 출발 계획, 날씨, 현재 구간과 차량 도착 정보를 확인합니다. 전체 지도 보기로 연결되며 현재 정보 확인은 저장 경로와 조회 가능한 날씨·차량 정보를 확인합니다. 추적 중이면 승차지까지 도보 시간도 확인합니다. |
| 설정 | 자동 추적, 위치 안내 표시, 12/24시간제, 알림 종류와 기준을 조절합니다. 기기 권한, 루틴 관리, 알림 로그, 로그아웃으로 연결됩니다. |
| 알림 로그 | 제목·본문·시각·읽음 상태를 확인하고 모두 읽음으로 바꿀 수 있습니다. |

실시간 이동의 **다음 대중교통**에서 시간값을 받은 열차는 남은 시간을 표시합니다. 열차 위치만 받은 경우에는 `2정거장 전 · 송파`와 `도착 예정 시간 미제공`을 표시합니다. 확인된 방면은 별도 줄에서 볼 수 있습니다.

## 기상에 따른 출발 시각

루틴에서 **기상정보 반영**을 켜고 저장한 경로를 기본 출근길 또는 퇴근길로 지정하면, 앱이 출발 전에 등록 출발지의 기상청 단기예보를 확인합니다. 홈과 실시간 이동에 조정된 출발 시각과 앞당긴 분 수가 표시됩니다.

**출발 시각 = 목표 도착 시각 − 예상 이동시간 − 도착 여유시간 − 기상 보정분**

| 예보 | 기상 보정 |
| --- | --- |
| 비·소나기 또는 강수확률 60% 이상 | 5분 |
| 눈·진눈깨비 | 10분 |
| 0°C 이하 | 위 보정에 5분 추가 |
| 적용 상한 | 15분 |

눈·진눈깨비 예보에는 10분 기준을 적용합니다. 예를 들어 목표 도착 09:00, 이동 40분, 도착 여유 10분이면 기본 출발은 08:10입니다. 0°C 이하에서 눈이 예보되면 15분 앞당겨 07:55 출발을 안내합니다. 준비·출발 알림과 자동 위치 확인 시각에도 같은 기상 보정분을 적용합니다.

기상정보 반영이 꺼져 있거나 출발 시간대 예보를 예약 갱신 마감까지 확인할 수 없으면 기본 계산으로 안내합니다.

## 위치와 알림

- `설정 → 출퇴근 자동 위치 추적`을 켜면 예정 출발 30분 전부터 출발 시각까지 출발지 반경 500m를 확인합니다. 앱을 닫아둔 상태에서도 확인하려면 Android의 백그라운드 위치 권한을 허용합니다. 확인되지 않은 회차는 자동 안내와 예약 알림을 건너뜁니다.
- 이동 화면에서 수동 추적을 시작하면 새 위치로 같은 500m를 확인합니다. 출발지 범위 밖이면 안내가 시작되지 않습니다.
- 이동 시작 전에 정확한 위치가 반경 밖이면 `현재 출근 위치가 아닙니다.` 또는 `현재 퇴근 위치가 아닙니다.`가 표시됩니다. 시연할 때 `출퇴근 위치 안내 표시`를 끄면 화면 문구가 숨겨집니다. 이동 안내와 알림의 위치 조건은 그대로 적용됩니다.
- 자동 추적이 꺼진 경우 출발 준비와 출발 시각 알림은 시간 예약으로 동작합니다. 출발 알림과 이동 알림의 세부 조건은 [알림 동작](ALARM_FEATURES.md)에서 확인합니다.
