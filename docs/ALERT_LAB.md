# Debug 알림 실험실

Debug 앱의 **설정 → 알림 종류 펼치기 → 알림 테스트 모드 → 알림 시뮬레이터 열기**로 시작합니다. 테스트 모드를 켜면 실제 예약 알림과 위치 추적이 일시 중지됩니다. 일반 사용을 확인하려면 모드를 해제합니다.

| 메뉴 | 확인하는 내용 |
| --- | --- |
| 전체 알림 자동 검증 | 알림 조건을 일괄 검사하고 결과를 화면과 클립보드로 제공합니다. |
| 개별 시나리오·가상 시계 | 가상 조건을 조절해 하나의 알림 동작을 확인합니다. Android 시계와 일반 알림 예약은 별도로 유지됩니다. |
| 실제 API 양식·응답·오류 진단 | 사용 가능한 키와 네트워크로 요청해 응답 상태와 연동 오류를 확인합니다. |
| 경로 추천 로직 테스트 | 가상 후보나 저장 후보로 동일한 `WeatherRouteRanker`의 순위를 비교합니다. |
| GPS 경로 마커 테스트 | 경로 구간·진행률과 지도 약도 표시를 모의 조정합니다. |
| 지하철역 ETA 일괄 검사 | 역별 응답과 유효한 도착 시간 제공 여부를 알아봅니다. |

모의 알림의 화면 제목은 실사용 알림과 동일합니다. 내부 기록에만 테스트 유형을 부여하며 일반 알림 로그에는 표시되지 않습니다. 개발용 Activity와 메뉴는 `app/src/debug/`와 Debug 조건에 속합니다.

조건 모의 검사 결과와 실제 출퇴근 시 GPS·교통 API·절전 상태를 함께 검증한 결과는 구분합니다. [이전 실험실 기록](history/ALERT_LAB_2026-11-20.md) · [현재 검증 결과](STATUS.md)
