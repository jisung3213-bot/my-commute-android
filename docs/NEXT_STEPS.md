# 남은 확인 항목

## 과제 시연 전 점검

1. 과제용 Firebase 프로젝트와 테스트 계정으로 신규 가입, 로그아웃, 재로그인을 확인합니다. 루틴을 저장한 뒤 같은 계정으로 두 번째 기기에 로그인해 루틴과 알림 설정을 확인합니다.
2. 루틴 화면에서 장소 검색 결과를 선택하고, 출퇴근 양방향 경로를 검색해 저장합니다. 앱을 다시 열어 반복 요일, 목표 도착 시각, 지도에 표시되는 경로가 유지되는지 확인합니다.
3. 실제 기기에서 출발지 반경 안과 밖의 자동 추적을 각각 확인합니다. 화면 잠금·배터리 절약 상태에서 알림 발송 시각을 기록하고 홈의 알림 로그와 대조합니다.
4. 시연 직전에 장소 검색과 사용하는 노선의 실시간 도착 정보를 확인합니다. API 오류, ETA 없음, 위치 권한 거부에 대한 안내도 확인합니다.

## 후속 개발 범위

- 기상청 단기예보의 강수·기온은 이미 추천에 반영됩니다. 한파주의보·경보 등 공식 기상특보 연동은 별도 범위입니다.
- 전 구간 실시간 도착 추정과 확정적인 탑승 판정은 별도 범위입니다.
- 식사·커피 등 개인 일정과 경로 편의 시설은 후속 기능으로 보류합니다.

현재 근거는 [검증 결과](STATUS.md)와 [과제 요구사항 점검](REQUIREMENTS_CURRENT.md)에 정리했습니다.
