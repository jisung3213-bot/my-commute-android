- **화면 정보와 기술 상태 분리:** 홈·커스텀·실시간 이동·지도·장소 검색·로그인·알림 로그에서 개발용 설명 문장과 API/SDK/캐시 호출 안내를 일반 사용자 화면에서 제거했습니다. 실제 기능 동작은 유지합니다.
