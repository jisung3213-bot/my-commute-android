# 현재 구현 범위와 입력 책임

기준일: 2026-11-15. 이 문서는 이전 설계·검토 문서에서 아래 항목을 수정한다.

## 사용자 입력

- 출발지·도착지·요일·목표 도착시간·여유시간은 사용자가 앱의 루틴 등록 화면에서 입력한다.
- 개발을 위해 사용자에게 실제 출퇴근 정보를 미리 제출하도록 요구하거나 개인 경로를 기본값으로 넣지 않는다.
- 출근·퇴근은 별도 루틴으로 저장하는 방향으로 설계한다.

## 기상에 따른 경로 평가

- 우천 대안을 사용자가 미리 입력한 단일 경로/소요시간으로 대체하지 않는다.
- 실제 예보·특보를 정규화한 조건값을 if 분기로 처리하고 경로 후보에 서로 다른 가중치를 적용한다.
- 예: 비가 오면 도보 노출에 더 큰 비용을 부여하고 자전거 구간이 있는 경로는 제외한다.
- 예: 한파특보가 있으면 도보 및 실외 대기 비용을 높인다. 위험 이동수단 제외 정책은 강도별로 정의한다.
- 여러 조건이 겹치면 함께 반영한다. 정보가 없거나 오래된 경우 맑음으로 단정하지 않고 갱신시각과 미확인 상태를 알린다.
- 점수 예시: 예상 소요시간 + 도보시간×기상 가중치 + 실외대기시간×기상 가중치 + 환승 비용 + 지각 위험 비용.
- 이동수단 금지 조건은 점수 조정에 앞서 적용한다. 가중치 수치는 아직 확정하거나 검증하지 않았다.
- 점수는 후보 선택에 사용하며 가중치를 곱한 점수를 실제 이동시간으로 표시하지 않는다. 선택한 경로의 실제 예상시간과 목표 도착시간으로 출발 권장시각을 별도 계산한다.
- 현재 코드에서 실제 기상 API/특보 연동과 이 평가 로직이 구현 완료된 것은 아니다.

## 편의시설 보류

- 식사·커피·음식점 추천·체류시간 계산·관련 알림의 실제 구현은 후속 단계로 미룬다.
- 확장 예정이라는 표시와 설계상 확장 가능성만 남긴다. 필수 입력이나 핵심 출퇴근 완료 조건으로 삼지 않는다.
- 제공 ZIP에 있는 수동 식사/커피 입력·알림은 향후 통합 시 활성 기능에서 제외할 대상이다.

## 개발 환경

- 사용자가 업데이트 요청을 정정했다. **현재 Android Studio 버전과 설정을 유지한다.**
- 기존 AGP 8.2.0 / Gradle 8.2 / JDK 17 / compileSdk 34 / minSdk 26 / targetSdk 28 설정을 이번 작업에서 변경하지 않는다.
- 새 소스 반영 시 기존 환경에 맞게 코드·의존성을 호환화한다. 새 ZIP의 AGP 8.7.3 / Gradle 8.9 / SDK 35 요구를 그대로 적용하지 않는다.
- 업데이트 설치는 실행하지 않았다. 공식 설치 파일 다운로드와 별도 자료 폴더에 SDK 관리 도구 압축 해제만 진행했다. 이 파일들을 실행·설치하지 않는다.
