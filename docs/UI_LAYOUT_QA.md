### PR #2로 변경된 시간 입력 검증

- 커스텀 **목표 도착시각은 TimePicker**를 유지하고 **여유시간 0~180분은 NumberPicker**로 선택합니다.
- 설정에서 출발 준비(1~120분), 차량 도착 임박(1~30분), 승차 여유(0~20분), 지연 기준(1~60분), 새 루틴 기본 여유(0~120분)를 휠로 선택합니다.
- 확인/취소, 최솟값/최댓값, 저장 후 재진입, 방향 전환 후 값 유지, 작은 화면에서 대화상자 잘림 여부는 **병합 이후 별도 검증이 필요합니다**. 변경 전 에뮬레이터 기록을 변경 후의 검증으로 재사용하지 않습니다.

격리 에뮬레이터에서 320dp 너비, 글자 배율 1.3과 2.0의 월~일 한 줄 및 선택 저장은 직전 작업에서 확인했습니다. 실제 기기의 화면 잠금과 절전 모드 점검은 [남은 확인 항목](NEXT_STEPS.md)에 있습니다.
