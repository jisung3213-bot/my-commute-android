# 과제 기술 요구사항 점검

2026-11-23 로컬 앱 0.2.0 기준입니다. 제공된 평가표의 최소 요건을 코드와 실행 결과로 확인했습니다.

| 기술 요구사항 | 판정 | 현재 구현과 실행 근거 |
| --- | --- | --- |
| 화면 5~8개 이상, 화면 간 이동과 데이터 전달 | 충족 확인 | 일반 앱에 로그인·홈·루틴·장소 검색·지도·실시간 이동·설정·알림 로그의 Activity 8개가 있습니다. Android 14에서 로그인 화면과 나머지 화면을 확인했습니다. 장소 검색 결과의 장소명·위도·경도가 루틴으로 전달되고 저장되는 것을 확인했습니다. |
| BaaS 인증을 사용하는 회원가입·로그인 | 구현 확인 | 로그인 화면에서 Firebase Authentication의 이메일·비밀번호 회원가입과 로그인을 호출합니다. 원본 APK의 버튼 활성 상태와 Firebase의 잘못된 인증정보 응답을 확인했습니다. 실제 계정 생성 및 정상 로그인 성공은 미검증입니다. |
| 원격 저장 또는 로컬 저장 | 충족 확인 | 계정별 SharedPreferences의 루틴·설정, Room의 알림 기록, Firestore의 루틴·설정 동기화 코드가 있습니다. 실제 장소 검색 결과를 루틴에 저장하고 앱을 재시작해 장소명과 좌표가 유지되는 것을 확인했습니다. Firestore 다기기 동기화는 미검증입니다. |
| 외부 API 1개 이상 연동 | 충족 확인 | Android 14에서 TMAP 장소 검색 결과 10건을 파싱했고, 실제 장소 검색 UI에서 결과를 선택했습니다. 기상청 단기예보의 온도·강수확률 필드를 파싱했습니다. |

경로 결과 목록과 가입 버튼은 각각 루틴 화면과 로그인 화면에 포함됩니다.

## 구현 및 완성도 40점 항목

- **요건 충족**은 위 표의 항목별 구현과 실행 근거로 판단합니다.
- **핵심 기능 안정성**은 Debug·Release 빌드와 Lint로 점검했습니다. 실제 기기의 장시간 백그라운드 동작과 서비스 전체의 성공은 별도 시험 항목입니다.
- **사용성**은 하단 탐색, 홈 알림 로그 진입, 출퇴근 방향 표시, 장소 선택과 저장, 작은 화면의 반복 요일 표시로 확인했습니다. 검증 결과와 시연 순서를 따로 기록했습니다. [현재 검증 결과](STATUS.md) · [시연·UI 점검표](UI_LAYOUT_QA.md)
